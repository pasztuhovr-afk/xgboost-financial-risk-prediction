
# XGBoost Financial Risk Prediction

## Overview
A machine learning portfolio project exploring XGBoost
for financial risk prediction, with a focus on data
preprocessing, feature engineering, model development
and evaluation.

## Project Objectives
- Explore and preprocess financial datasets
- Develop predictive models using XGBoost
- Apply feature engineering techniques
- Evaluate model performance using appropriate metrics
- Document the methodology and results

## Tech Stack
- Python
- XGBoost
- Pandas and NumPy
- Scikit-learn
- Jupyter Notebook
